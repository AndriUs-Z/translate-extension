# ส่วนขยายแปลหน้าเว็บ (อังกฤษ ⇄ ไทย)

กดปุ่มเดียวเพื่อแปลหน้าเว็บที่เปิดอยู่ (หรือข้อความที่ลากเลือกไว้) ผลการแปลจะแสดงในแท็บใหม่ และคำแปลถูกเก็บไว้ในเครื่องของคุณ ใช้ได้กับ **Chrome, Edge, Brave, Opera และ Firefox**

## วิธีติดตั้ง

### ขั้นที่ 1: ดาวน์โหลดและแตกไฟล์
1. ดาวน์โหลดไฟล์ [`translate_extension.zip`](https://github.com/AndriUs-Z/translate-extension/releases/latest/download/translate_extension.zip) (หรือเข้าหน้า [Releases](https://github.com/AndriUs-Z/translate-extension/releases/latest) แล้วเลือกไฟล์เอง)
2. คลิกขวาที่ไฟล์ → **Extract All / แตกไฟล์** แล้วเก็บโฟลเดอร์ไว้ในที่ที่จะไม่ลบทิ้ง (เช่น `Documents\translate_extension`)

> ⚠️ **อย่าลบหรือย้ายโฟลเดอร์หลังติดตั้ง** เพราะเบราว์เซอร์อ่านส่วนขยายจากโฟลเดอร์นี้โดยตรง

### ขั้นที่ 2: ติดตั้งตามเบราว์เซอร์ที่ใช้

#### Chrome / Brave
1. พิมพ์ `chrome://extensions` ในช่อง address bar แล้วกด Enter
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. กดปุ่ม **Load unpacked**
4. เลือกโฟลเดอร์ที่แตกไฟล์ไว้ (โฟลเดอร์ที่มีไฟล์ `manifest.json` อยู่ข้างใน)

#### Microsoft Edge
1. พิมพ์ `edge://extensions` แล้วกด Enter
2. เปิดสวิตช์ **Developer mode** (เมนูซ้ายล่างหรือมุมซ้าย)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ที่แตกไฟล์ไว้

#### Opera
1. พิมพ์ `opera://extensions` แล้วกด Enter
2. เปิด **Developer mode** แล้วกด **Load unpacked** เลือกโฟลเดอร์ที่แตกไฟล์ไว้

#### Firefox
1. พิมพ์ `about:debugging#/runtime/this-firefox` แล้วกด Enter
2. กด **Load Temporary Add-on...**
3. เลือกไฟล์ `manifest.json` ในโฟลเดอร์ที่แตกไฟล์ไว้

> Firefox แบบนี้เป็นการติดตั้ง **ชั่วคราว** ส่วนขยายจะหายเมื่อปิด Firefox และต้องทำขั้นตอนนี้ใหม่ทุกครั้งที่เปิด

### ขั้นที่ 3: ปักหมุดไอคอน (ทำครั้งเดียว)
กดไอคอนรูปจิ๊กซอว์ (Extensions) ข้างช่อง address bar แล้วกดปักหมุดข้างชื่อ **แปลหน้านี้** เพื่อให้ไอคอนอยู่บนแถบเครื่องมือ

## วิธีใช้
1. เปิดหน้าเว็บที่ต้องการแปล
2. (ไม่บังคับ) ลากเลือกข้อความที่ต้องการแปลเฉพาะส่วน
3. กดไอคอนส่วนขยาย
4. แท็บใหม่จะเปิดขึ้นพร้อมผลการแปล ระบบเลือกทิศทางให้เองจากภาษาของข้อความ (มีอักษรไทยเป็นหลัก = ไทย → อังกฤษ นอกนั้น = อังกฤษ → ไทย)

ในหน้าผลการแปลมีปุ่ม **คัดลอกคำแปลทั้งหมด** และ **ล้างแคชคำแปลในเครื่อง**

## คำถามที่พบบ่อย

**กดแล้วขึ้นว่า "หน้านี้แปลไม่ได้"**
ส่วนขยายอ่านได้เฉพาะหน้าเว็บทั่วไป (http/https) ไม่รองรับหน้าตั้งค่าของเบราว์เซอร์ (`chrome://...`), หน้าสโตร์ส่วนขยาย, รูปภาพ และไฟล์ PDF ที่เปิดในเบราว์เซอร์

**แปลช้า หรือค้างตอนแรก**
เซิร์ฟเวอร์แปลอยู่บนบริการแบบฟรีซึ่งจะ "หลับ" เมื่อไม่มีคนใช้ ครั้งแรกอาจต้องรอประมาณ 1 นาทีให้เซิร์ฟเวอร์ตื่น และหน้ายาวๆ ใช้เวลานาน (ส่วนขยายแปลสูงสุด 8,000 ตัวอักษรหรือ 120 ท่อนต่อครั้ง) ท่อนที่แปลแล้วจะถูกเก็บไว้ ลองกดใหม่ได้โดยไม่ต้องเริ่มต้นใหม่ทั้งหมด

**Chrome / Edge ขึ้นคำเตือนเรื่อง Developer mode ทุกครั้งที่เปิดเบราว์เซอร์**
เป็นเรื่องปกติของส่วนขยายที่ติดตั้งนอกสโตร์ กดปิดคำเตือนได้ ไม่กระทบการใช้งาน

**อัปเดตเวอร์ชันใหม่ทำอย่างไร**
ดาวน์โหลด zip ใหม่ แตกไฟล์ทับโฟลเดอร์เดิม แล้วเข้าหน้า extensions กดปุ่มโหลดซ้ำ (รูปลูกศรวนที่การ์ดของส่วนขยาย)

**ถอนการติดตั้ง**
เข้าหน้า extensions แล้วกด Remove ที่การ์ด **แปลหน้านี้** จากนั้นลบโฟลเดอร์ที่แตกไว้ได้

## ความเป็นส่วนตัว
- ส่วนขยายอ่านข้อความเฉพาะ **แท็บที่คุณกดไอคอน** เท่านั้น ไม่อ่านหน้าเว็บอื่นอัตโนมัติ
- ข้อความที่อ่านได้จะถูกส่งไปยังเซิร์ฟเวอร์แปลของโครงการนี้เพื่อแปล จึง **อย่าใช้กับหน้าที่มีข้อมูลส่วนตัวหรือความลับ**
- คำแปลที่ได้ถูกเก็บในเครื่องของคุณ (storage ของส่วนขยาย) และล้างได้จากปุ่มในหน้าผลการแปล
- สิทธิ์ที่ขอมีเพียง `activeTab` (อ่านแท็บปัจจุบันเฉพาะตอนกดปุ่ม), `scripting` และ `storage`

## ข้อจำกัด
- **Safari** และ **Chrome บน Android** ยังไม่รองรับ (Firefox บน Android ติดตั้งได้ผ่านวิธีของ Firefox สำหรับนักพัฒนา)
- โมเดลแปลฝึกกับประโยคและคำศัพท์ ย่อหน้ายาวหรือข้อความเมนู/ปุ่มที่ปนในหน้าอาจแปลได้ไม่ดี

## สำหรับผู้พัฒนา

### โครงสร้าง
```
extension/    โค้ดส่วนขยาย (Manifest V3, ใช้ได้ทั้ง Chrome/Edge/Firefox)
tests/        ทดสอบตรรกะ: node tests/lib.test.js
```

### ตั้งค่า
แก้ `extension/config.js`: ใส่ `API_URL_TH_EN` และ `API_URL_EN_TH` (ลงท้าย `/translate`) ถ้าใช้ API เดียวที่รองรับสองทิศทาง ใส่ URL เดียวกันทั้งคู่ ค่าอื่น (`MAX_CHARS`, `MAX_CHUNKS`, `CACHE_MAX_ENTRIES`) ปรับได้ในไฟล์เดียวกัน

> ไฟล์นี้อยู่ใน repo สาธารณะ URL ของ API จะมองเห็นได้โดยทุกคน

### สร้างไฟล์ zip สำหรับ Release
ใน PowerShell ที่โฟลเดอร์ของ repo (ต้องให้ `manifest.json` อยู่ชั้นนอกสุดของ zip):
```
Compress-Archive -Path extension\* -DestinationPath translate_extension.zip -Force
```
จากนั้นที่หน้า repo → **Releases** → **Create a new release** → ตั้ง tag เช่น `v1.0.0` → แนบไฟล์ `translate_extension.zip` (ชื่อไฟล์ต้องตรงกับลิงก์ดาวน์โหลดด้านบน) → **Publish release**
